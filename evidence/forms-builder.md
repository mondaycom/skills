## Open questions

- Default layout of a new form (OneByOne, and CARD or FLAT) is platform behavior that the code does not show. The skill keeps the original "new forms default to OneByOne" from the previous version.
- `get_board_info` in production: the live description does not name `url` in the response. If it is absent, take the board URL from a `search` BOARD result instead.
- Platform behaviors the skill states but code cannot confirm: header defaults to "New Form"; `hideBranding` silently fails below Pro; select `value` normalization; PAGE_BLOCK ID reassignment on reorder; region codes other than `use1` for `?r=`.
